# ระบบกรอกคะแนนการแข่งขันทักษะวิชาชีพ

เว็บแอปสำหรับให้กรรมการกรอกคะแนนการแข่งขัน **ทักษะการพัฒนานวัตกรรมเทคโนโลยีธุรกิจดิจิทัล (ปวส.)** ตามเกณฑ์ในชีต
[แบบบันทึกคะแนน การแข่งขันทักษะวิชาชีพ](https://docs.google.com/spreadsheets/d/180aKYvvlwqozAcXar6j9gTo6wGA7kSeir13wxSw0nEM/edit)
ระบบจะรวมคะแนนจากกรรมการทุกคน ตัดสินระดับเหรียญ และดาวน์โหลดเป็นไฟล์ Excel (.xlsx) ได้

## ความสามารถ

- **เข้าสู่ระบบแยกตามบทบาท** — คะแนนทุกข้อบันทึกลงฐานข้อมูล SQLite บนเซิร์ฟเวอร์ กรรมการกรอกคนละเครื่องได้พร้อมกัน
  - **กรรมการ**: เข้าด้วย **เบอร์โทรศัพท์อย่างเดียว** (ไม่ต้องลงทะเบียน ไม่มีรหัสผ่าน) พิมพ์เบอร์แล้วระบบแสดง
    **"กรรมการคนที่ N"** และชื่อ ตามลำดับรายชื่อที่ผู้ดูแลระบบตั้งไว้ — กรอกและเห็นได้เฉพาะคะแนนของตัวเอง
  - **ผู้ดูแลระบบ (Admin)**: กด "เข้าระบบ Admin" ใช้ชื่อผู้ใช้ + รหัสผ่าน — เพิ่มกรรมการ (ชื่อ + เบอร์โทร) จัดการทีม
    ดูคะแนนของกรรมการทุกคน (ดูอย่างเดียว) สรุปผล และดาวน์โหลด Excel
- **กรอกคะแนนง่าย**: เลือกทีม → แตะปุ่มคะแนน (0, 0.5, 1, …) หรือพิมพ์ตัวเลขเองก็ได้ ระบบไม่ให้กรอกเกินคะแนนเต็มของข้อนั้น (ตรวจซ้ำที่เซิร์ฟเวอร์)
- แสดงคะแนนรวมรายด้านและคะแนนรวมทั้งหมด (เต็ม 100) แบบทันที พร้อมแถบบอกว่ากรอกครบแล้วกี่ข้อ
- **ปุ่มบันทึก / แก้ไข**: กรรมการกด **💾 บันทึก** เมื่อให้คะแนนทีมนั้นเสร็จ คะแนนจะถูกล็อก (🔒) ไม่ให้แก้โดยไม่ตั้งใจ
  ถ้าต้องการเปลี่ยนคะแนน กด **✏️ แก้ไข** เพื่อปลดล็อก แล้วกดบันทึกอีกครั้ง
- **เพิ่ม/ลบ/แก้ชื่อและเบอร์โทรกรรมการ** และ **เพิ่ม/ลบทีม** พร้อมชื่อสถานศึกษา (เฉพาะผู้ดูแลระบบ)
- **สรุปผล**: จัดอันดับทีม แสดงคะแนนจากกรรมการแต่ละคน สถานะบันทึก คะแนนเฉลี่ย ระดับเหรียญ และคะแนนเฉลี่ยรายด้าน
  (อัปเดตจากฐานข้อมูลอัตโนมัติทุก 15 วินาที)
- **ดาวน์โหลด Excel (.xlsx)** — ชื่อกรรมการอยู่ในช่องลงชื่อด้านล่างของทุกชีต
  - **Excel สรุปคะแนน**: ชีต "สรุปคะแนน" + ชีต "กรรมการ1, กรรมการ2, …" ครบในไฟล์เดียว (โครงเดียวกับ Google Sheet ต้นฉบับ)
  - **Excel ใบให้คะแนนรายกรรมการ**: ทุกข้อของเกณฑ์ × ทุกทีม เฉพาะกรรมการคนนั้น
  - ในไฟล์ใช้สูตร Excel (SUM / AVERAGE / IF) ถ้าแก้คะแนนในไฟล์ ผลรวม คะแนนเฉลี่ย และเหรียญจะคำนวณใหม่เอง
  - ถ้ายังมีคะแนนที่ยังไม่กดบันทึก ระบบจะเตือนพร้อมรายชื่อก่อนดาวน์โหลด
- ดาวน์โหลดไฟล์สำรองข้อมูลทั้งหมดเป็น `.json` ได้

## วิธีใช้งาน

### ใช้งานออนไลน์ (Cloudflare)

ระบบขึ้นไว้ที่ **https://scoll-dbt.phatthachada-k.workers.dev** (Cloudflare Workers + ฐานข้อมูล D1)

- กรรมการเปิดลิงก์นี้จากมือถือ/คอมพิวเตอร์ได้ทุกที่ แล้วพิมพ์เบอร์โทรศัพท์
- ผู้ดูแลระบบกด "เข้าระบบ Admin" ชื่อผู้ใช้ `admin` (รหัสผ่านตั้งเป็น secret `ADMIN_PASSWORD` บน Cloudflare)

อัปเดตระบบหลังแก้โค้ด:

```bash
npm install
npx wrangler login          # ครั้งแรกครั้งเดียว
npm run cf:deploy           # สร้าง/อัปเดตตารางใน D1 แล้ว deploy
```

- ทดสอบในเครื่องก่อน deploy: สร้างไฟล์ `.dev.vars` ใส่ `ADMIN_PASSWORD=...` แล้วรัน `npm run cf:dev`
- ตั้งรหัสผ่านผู้ดูแลระบบครั้งแรก (ใช้เฉพาะตอนที่ยังไม่มีบัญชี admin): `npx wrangler secret put ADMIN_PASSWORD`
- สำรองฐานข้อมูล: `npx wrangler d1 export scoll-dbt --remote --output backup.sql`

ไฟล์ที่เกี่ยวข้อง: `worker/index.js` (API), `migrations/` (โครงสร้างตาราง D1), `wrangler.jsonc` (ตั้งค่า Cloudflare)

### ติดตั้งและเปิดเซิร์ฟเวอร์ในวงแลน (Node.js — ไม่ต้องใช้อินเทอร์เน็ต)

ต้องมี **Node.js 22.13 ขึ้นไป** (ใช้ฐานข้อมูล SQLite ที่มากับ Node.js ไม่ต้องติดตั้งฐานข้อมูลแยก)

```bash
npm install
npm start
```

- ครั้งแรกระบบจะสร้างบัญชี **ผู้ดูแลระบบ** ชื่อผู้ใช้ `admin` พร้อมรหัสผ่านสุ่ม แสดงในหน้าต่างที่รัน `npm start`
  (กำหนดเองได้ด้วยตัวแปร `ADMIN_PASSWORD` ก่อนรันครั้งแรก) — เข้าระบบแล้วเปลี่ยนรหัสผ่านได้ที่ปุ่ม "เปลี่ยนรหัสผ่าน"
- หน้าต่างจะแสดงที่อยู่ให้กรรมการเปิด เช่น `http://192.168.1.10:3000` (เครื่องอยู่ในวงแลน/Wi-Fi เดียวกัน)
- ข้อมูลทั้งหมดเก็บที่ไฟล์ `data/score.db` — สำรองไฟล์นี้ไว้ก็ได้ข้อมูลครบ

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `PORT` | `3000` | พอร์ตของเว็บ |
| `DB_FILE` | `data/score.db` | ที่เก็บไฟล์ฐานข้อมูล |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | `admin` / สุ่ม | บัญชีผู้ดูแลระบบที่สร้างตอนรันครั้งแรก |

> ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์ Sarabun และไลบรารีสร้างไฟล์ Excel (ExcelJS)

### ขั้นตอน

1. **ผู้ดูแลระบบ** กด "เข้าระบบ Admin" → แท็บ **ตั้งค่า**: แก้ชื่อการแข่งขัน หัวกระดาษ วันที่ สถานที่
   เพิ่ม **กรรมการ (ชื่อ + เบอร์โทรศัพท์)** ตามลำดับ (คนแรก = กรรมการคนที่ 1) และเพิ่มทีมพร้อมชื่อสถานศึกษา
2. **กรรมการ** เปิดเว็บ พิมพ์เบอร์โทรศัพท์ → ตรวจว่าชื่อและ "กรรมการคนที่ N" ถูกต้อง → กดเข้าสู่ระบบ
   เลือกทีม ให้คะแนนทีละข้อ (บันทึกลงฐานข้อมูลทันที) กด **"💾 บันทึก"** เมื่อเสร็จ แล้วกด **"ทีมถัดไป →"**
   - จุดสีบนปุ่มทีม: เทา = ยังไม่กรอก, เหลือง = กรอกบางส่วน, เขียว = ครบทุกข้อ, 🔒 = บันทึกแล้ว
   - ต้องการแก้คะแนนที่บันทึกแล้ว กด **"✏️ แก้ไข"** → เปลี่ยนคะแนน → กด **"💾 บันทึก"** อีกครั้ง
3. **ผู้ดูแลระบบ** แท็บ **สรุปผล**: ตรวจว่าทุกช่องขึ้น "🔒 บันทึกแล้ว" แล้วกด **"ดาวน์โหลด Excel สรุปคะแนน"**
   หรือดาวน์โหลดใบให้คะแนนของกรรมการแต่ละคน
   - ถ้ากรรมการคนใดกรอกไม่ครบ คะแนนจะมีเครื่องหมาย `*` กำกับ (ในไฟล์ Excel เป็นตัวเลขสีส้ม)

### ความปลอดภัย

- กรรมการเข้าระบบด้วยเบอร์โทรอย่างเดียว ใครรู้เบอร์ก็เข้าแทนได้ — ควรใช้ในวงแลนของสนามแข่ง ไม่เปิดสู่อินเทอร์เน็ต
- พิมพ์เบอร์/รหัสผ่านผิดเกิน 10 ครั้งใน 10 นาที ต้องรอ 10 นาที (กันการไล่สุ่มเบอร์)
- รหัสผ่านผู้ดูแลระบบเข้ารหัสด้วย bcrypt, session เก็บใน cookie แบบ HttpOnly
- เซิร์ฟเวอร์ตรวจสิทธิ์ทุกคำขอ: กรรมการแก้ได้เฉพาะคะแนนของตัวเอง และแก้คะแนนที่ล็อก (🔒) แล้วไม่ได้

## โครงสร้างไฟล์

```
server/server.js         เซิร์ฟเวอร์ Express: เข้าสู่ระบบ, API บันทึกคะแนน, จัดการกรรมการ/ทีม
server/db.js             ฐานข้อมูล SQLite (ตาราง users, sessions, teams, scores, saved, settings)
public/index.html        หน้าเว็บหลัก
public/css/style.css     รูปแบบหน้าจอ
public/js/criteria.js    เกณฑ์การให้คะแนนทั้งหมด และเกณฑ์เหรียญ (ใช้ร่วมกันทั้งหน้าเว็บและเซิร์ฟเวอร์)
public/js/app.js         หน้าเว็บ (เข้าสู่ระบบ กรอกคะแนน บันทึก/แก้ไข สรุปผล ส่งออก Excel)
data/score.db            ไฟล์ฐานข้อมูล (สร้างอัตโนมัติ ไม่เก็บใน git)
```

### การแก้ไขเกณฑ์

แก้ไขที่ `public/js/criteria.js` ได้โดยตรง (แล้วรีสตาร์ตเซิร์ฟเวอร์) เช่น เปลี่ยนคะแนนเต็มของข้อ (`max`) ข้อความรายละเอียด (`details`)
หรือช่วงคะแนนเหรียญใน `MEDALS` ระบบจะคำนวณคะแนนเต็มรวมใหม่ให้อัตโนมัติ
