# ระบบกรอกคะแนนการแข่งขันทักษะวิชาชีพ

เว็บแอปสำหรับให้กรรมการกรอกคะแนนการแข่งขัน **ทักษะการพัฒนานวัตกรรมเทคโนโลยีธุรกิจดิจิทัล (ปวส.)** ตามเกณฑ์ในชีต
[แบบบันทึกคะแนน การแข่งขันทักษะวิชาชีพ](https://docs.google.com/spreadsheets/d/180aKYvvlwqozAcXar6j9gTo6wGA7kSeir13wxSw0nEM/edit)
ระบบจะรวมคะแนนจากกรรมการทุกคน ตัดสินระดับเหรียญ และดาวน์โหลดเป็นไฟล์ Excel (.xlsx) ได้

## ความสามารถ

- **กรอกคะแนนง่าย**: เลือกกรรมการ → เลือกทีม → แตะปุ่มคะแนน (0, 0.5, 1, …) หรือพิมพ์ตัวเลขเองก็ได้ ระบบไม่ให้กรอกเกินคะแนนเต็มของข้อนั้น
- แสดงคะแนนรวมรายด้านและคะแนนรวมทั้งหมด (เต็ม 100) แบบทันที พร้อมแถบบอกว่ากรอกครบแล้วกี่ข้อ
- **ปุ่มบันทึก / แก้ไข**: กรรมการกด **💾 บันทึก** เมื่อให้คะแนนทีมนั้นเสร็จ คะแนนจะถูกล็อก (🔒) ไม่ให้แก้โดยไม่ตั้งใจ
  ถ้าต้องการเปลี่ยนคะแนน กด **✏️ แก้ไข** เพื่อปลดล็อก แล้วกดบันทึกอีกครั้ง
- **เพิ่ม/ลบ/แก้ชื่อกรรมการ** ได้ (ค่าเริ่มต้นมี 3 คน)
- **เพิ่ม/ลบทีม** และใส่ชื่อสถานศึกษาได้
- **สรุปผล**: จัดอันดับทีม แสดงคะแนนจากกรรมการแต่ละคน สถานะบันทึก คะแนนเฉลี่ย ระดับเหรียญ และคะแนนเฉลี่ยรายด้าน
- **ดาวน์โหลด Excel (.xlsx)** — ชื่อกรรมการอยู่ในช่องลงชื่อด้านล่างของทุกชีต
  - **Excel สรุปคะแนน**: ชีต "สรุปคะแนน" + ชีต "กรรมการ1, กรรมการ2, …" ครบในไฟล์เดียว (โครงเดียวกับ Google Sheet ต้นฉบับ)
  - **Excel ใบให้คะแนนรายกรรมการ**: ทุกข้อของเกณฑ์ × ทุกทีม เฉพาะกรรมการคนนั้น
  - ในไฟล์ใช้สูตร Excel (SUM / AVERAGE / IF) ถ้าแก้คะแนนในไฟล์ ผลรวม คะแนนเฉลี่ย และเหรียญจะคำนวณใหม่เอง
  - ถ้ายังมีคะแนนที่ยังไม่กดบันทึก ระบบจะเตือนพร้อมรายชื่อก่อนดาวน์โหลด
- บันทึกอัตโนมัติในเบราว์เซอร์ ปิดหน้าแล้วเปิดใหม่ข้อมูลยังอยู่
- ส่งออก/นำเข้าไฟล์ `.json` สำหรับสำรองข้อมูล หรือรวมคะแนนจากหลายเครื่อง

## เกณฑ์การตัดสิน

คะแนนเฉลี่ย = ผลรวมคะแนนของกรรมการทุกคน ÷ จำนวนกรรมการ (ทศนิยม 2 ตำแหน่ง)

| คะแนนเฉลี่ย | ระดับเหรียญ |
|---|---|
| 80 – 100 | 🥇 เหรียญทอง |
| 70 – 79.99 | 🥈 เหรียญเงิน |
| 60 – 69.99 | 🥉 เหรียญทองแดง |
| ต่ำกว่า 60 | เกียรติบัตรเข้าร่วม |

## วิธีใช้งาน

### เปิดโปรแกรม

ไม่ต้องติดตั้งอะไรเพิ่ม เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (Chrome / Edge / Safari) ได้เลย
หรือจะรันผ่านเว็บเซิร์ฟเวอร์ก็ได้ เช่น

```bash
npx serve .
# หรือ
python -m http.server 8000
```

> ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์ Sarabun และไลบรารีสร้างไฟล์ Excel (ExcelJS)
> ถ้าออฟไลน์ ยังกรอกคะแนนได้ตามปกติ แต่ปุ่มดาวน์โหลด Excel จะใช้ไม่ได้จนกว่าจะต่อเน็ต

### ขั้นตอน

1. **ตั้งค่า**: แก้ชื่อการแข่งขัน หัวกระดาษ วันที่ สถานที่ ใส่ชื่อกรรมการ และเพิ่มทีมพร้อมชื่อสถานศึกษา
2. **กรอกคะแนน**: เลือกชื่อกรรมการ เลือกทีม แล้วให้คะแนนทีละข้อ กด **"💾 บันทึก"** เมื่อเสร็จ แล้วกด **"ทีมถัดไป →"**
   - จุดสีบนปุ่มทีม: เทา = ยังไม่กรอก, เหลือง = กรอกบางส่วน, เขียว = ครบทุกข้อ, 🔒 = บันทึกแล้ว
   - ต้องการแก้คะแนนที่บันทึกแล้ว กด **"✏️ แก้ไข"** → เปลี่ยนคะแนน → กด **"💾 บันทึก"** อีกครั้ง
3. **สรุปผล**: ตรวจว่าทุกช่องขึ้น "🔒 บันทึกแล้ว" แล้วกด **"ดาวน์โหลด Excel สรุปคะแนน"** หรือดาวน์โหลดใบให้คะแนนของกรรมการแต่ละคน
   - ถ้ากรรมการคนใดกรอกไม่ครบ คะแนนจะมีเครื่องหมาย `*` กำกับ (ในไฟล์ Excel เป็นตัวเลขสีส้ม)

### กรณีกรรมการกรอกคนละเครื่อง

ข้อมูลเก็บแยกตามเบราว์เซอร์ของแต่ละเครื่อง ถ้าจะรวมคะแนน:

1. เครื่องกลางตั้งค่ากรรมการและทีมให้เรียบร้อย แล้วกด **ส่งออกไฟล์ข้อมูล (.json)**
2. ส่งไฟล์ให้กรรมการแต่ละคนกด **นำเข้าและรวมคะแนน** ที่เครื่องของตัวเอง แล้วกรอกคะแนน
3. กรรมการแต่ละคน **ส่งออกไฟล์ข้อมูล** ส่งกลับมา
4. เครื่องกลาง **นำเข้าและรวมคะแนน** ทีละไฟล์ → ไปที่ "สรุปผล" แล้วดาวน์โหลด Excel (สถานะ 🔒 บันทึกแล้ว ติดมากับไฟล์ด้วย)

> ต้องเริ่มจากไฟล์ตั้งค่าเดียวกัน เพราะระบบจับคู่กรรมการและทีมด้วยรหัสภายใน ไม่ใช่ด้วยชื่อ

## โครงสร้างไฟล์

```
index.html        หน้าเว็บหลัก
css/style.css     รูปแบบหน้าจอ
js/criteria.js    เกณฑ์การให้คะแนนทั้งหมด และเกณฑ์เหรียญ (แก้ไขเกณฑ์ที่ไฟล์นี้)
js/app.js         การทำงานของระบบ (กรอกคะแนน บันทึก/แก้ไข สรุปผล ส่งออก Excel นำเข้า/ส่งออก JSON)
```

### การแก้ไขเกณฑ์

แก้ไขที่ `js/criteria.js` ได้โดยตรง เช่น เปลี่ยนคะแนนเต็มของข้อ (`max`) ข้อความรายละเอียด (`details`)
หรือช่วงคะแนนเหรียญใน `MEDALS` ระบบจะคำนวณคะแนนเต็มรวมใหม่ให้อัตโนมัติ
